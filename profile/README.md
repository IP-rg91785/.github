<h2>电脑端设置，先判断该改哪一层</h2>
<p>Windows 上「设置美国静态 IP」，可以指三种完全不同的操作：改系统代理、改网卡参数、或用客户端接管流量。三者的覆盖范围不同，配错了会出现「浏览器能用、后台工具不能用」这类问题。</p>
<p>先判断需求：只让浏览器走，还是整机都要走。判断清楚，再选层级。</p>

<p>网卡参数最彻底，也最危险：配错会整机断网。改之前务必记录原参数，并准备好一键恢复的方式。</p>

<h2>方式一：系统代理设置</h2>
<p>打开设置，进入网络和 Internet，找到代理，在手动设置里填地址与端口，保存。也可以用 Internet 选项的连接页配置，效果一致。</p>
<p>配完用浏览器查出口确认。若浏览器生效而目标工具不生效，说明该工具不读系统代理，需要换方式。</p>

<h3>认证信息的处理</h3>
<p>系统代理对需要账号密码的代理支持有限，常反复弹窗。遇到这种情况，改用支持认证的客户端更省事。</p>
<h3>命令行设置</h3>
<p>经常切换的话，用命令行更快，也便于写成脚本。注意部分设置只对当前会话生效，需要在启动项里固化。</p>

<h2>方式二：网卡参数</h2>
<p>打开网络连接，右键当前网卡进入属性，选择 Internet 协议版本，改为手动，依次填地址、掩码、网关、DNS。</p>
<p>四项里，掩码与网关最容易出错。掩码错会误判可用地址范围；网关错则完全不通。DNS 建议改为美国解析，避免解析泄漏。</p>

<h2>方式三：客户端接管</h2>
<p>安装客户端，导入配置，选择全局或规则模式。规则模式下只有命中规则的流量走代理，其余直连。</p>
<p>关键点是规则是否覆盖目标应用。配完要逐应用验证，而不是只测浏览器。</p>

<h2>配置后的四项验证</h2>
<p>一，出口地址与归属地正确。二，DNS 解析与出口同地区。三，目标应用逐个生效。四，断线时是否回落本地。</p>
<p>第四项最容易被忽略。开启断线阻断可以避免静默回落，代价是断线时无法上网。</p>

<h2>跨境电商场景的额外注意</h2>
<p>一，出口固定。不要今天美东明天美西，同一店铺应固定在同一个地区。二，设备固定。换设备会引入新的指纹变量。三，时区与语言对齐。系统设置里改，成本极低。</p>
<p>三项里，第一项最常被违反。有人为了「更真实」而随机切换城市，实际效果相反。</p>

<h2>常见故障</h2>
<p>故障一，改完网卡后完全断网。多为掩码或网关填错，改回自动获取即可恢复。</p>
<p>故障二，浏览器能用工具不能用。多为工具不读系统代理，改用客户端接管。</p>
<p>故障三，速度慢但带宽未满。多为加密开销或并发触顶。</p>
<p>故障四，重启后配置丢失。多为其他软件在启动时改写了设置。</p>

<h2>配置前先准备两样东西</h2>
<p>一是原配置的记录，二是回退的方法。改网卡参数前，把原来的地址获取方式与 DNS 截图保存；改系统代理前，记下原来的设置值。这两样东西的价值只在出错时体现，但出错时的价值极高——很多人卡在「忘了原来是什么」，最后只能重装或找同事的机器对照。</p>
<p>回退方法也要具体到操作：改回自动获取、关闭代理、恢复备份文件。写在纸上或文档里，不要只记在脑子里。配置出错时人容易慌，照着写好的步骤做，比临场判断可靠。</p>
<h2>常见问答</h2>
<h3>系统代理和 VPN 有什么区别</h3>
<p>系统代理只影响读设置的软件，VPN 或客户端在网络层截获流量，覆盖更全。</p>
<h3>一台电脑能同时用两个出口吗</h3>
<p>可以，用多网卡加路由规则。但要明确哪些程序走哪个出口，否则身份混乱。</p>
<h3>改网卡会影响局域网吗</h3>
<p>会。网关指向外部后，局域网共享资源可能无法访问。需要局域网时用路由规则分流，而不是改默认网关。</p>
<h3>需要装专用软件吗</h3>
<p>支持标准协议的方案不必装。专用软件功能更多，但增加依赖。</p>
